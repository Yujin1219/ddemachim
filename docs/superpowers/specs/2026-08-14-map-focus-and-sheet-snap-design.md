# 지도 집중 모드와 2단계 시트 설계

- 상태: 사용자 승인 완료
- 작성일: 2026-08-14
- 적용 범위: `FE/**`

## 목표

홈 지도 위의 상단 검색 UI와 선택 장소 시트가 지도를 과도하게 가리지 않게 한다. 사용자는 닫기 버튼 없이 시트를 손가락으로 접고 펼치며, 지도 빈 공간을 누르면 검색 UI를 작은 복귀 버튼으로 축소할 수 있어야 한다.

## 동작

- 선택 장소 시트의 `X` 버튼을 제거한다. 장소 선택은 유지되고 새 마커를 누르면 교체된다.
- 핸들 전체를 최소 44px 터치 영역으로 만든다.
- 핸들을 탭하면 펼침과 접힘 상태가 전환된다.
- 아래로 28px 이상 이동하거나 초속 280px 이상으로 놓으면 접힌다. 반대 방향은 펼쳐진다.
- 접힘 상태는 하단 내비게이션 위에 약 60px만 남겨 핸들과 선택 장소의 존재를 보여준다.
- 지도 빈 공간이나 장소 마커를 누르면 `오늘, 어디로 걸어볼까요?`, 검색창, 필터를 숨긴다.
- 숨김 상태에는 상단 우측에 최소 44px의 검색 복귀 버튼 하나만 남긴다.
- 검색 복귀 버튼을 누르면 제목, 검색창, 필터를 다시 보여준다.
- 장소 선택 시 상단은 자동 축소되고 선택 시트는 펼쳐진다.
- `광화문 출발`은 장소 카드 아래의 작은 보조 문구로 유지한다.

## 접근성과 모션

- 핸들은 `aria-expanded`로 상태를 알리고 동작을 이름으로 제공한다.
- 검색 복귀 버튼은 `검색 및 필터 펼치기` 접근성 이름을 갖는다.
- 시트는 드래그 중 손가락을 1:1로 따라가고 놓은 속도를 반영하는 스프링으로 스냅한다.
- `prefers-reduced-motion`에서는 큰 이동감을 줄이고 상태는 즉시 명확하게 바뀐다.

## 완료 기준

- 선택 시트에 `X`가 없다.
- 핸들 탭과 상하 드래그로 두 상태가 안정적으로 전환된다.
- 접힌 시트가 약 60px만 남고 하단 내비게이션과 겹치지 않는다.
- 지도 클릭과 장소 선택은 상단 UI를 작은 검색 버튼으로 축소한다.
- 작은 검색 버튼으로 상단 UI를 복원할 수 있다.
- 기존 장소 카드, 경로 비교, 대중교통 숨김, 택시 호출 기능이 유지된다.
