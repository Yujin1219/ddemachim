# 지도 카테고리와 혼잡도 컨트롤 재구성

- 상태: 사용자 승인 완료
- 작성일: 2026-08-14
- 적용 범위: `FE/**`

## 목표

지도 홈에서 장소 분류 필터와 혼잡도 레이어 설정을 서로 다른 기능으로 즉시 인식할 수 있게 한다. 카테고리는 사용자가 이해하기 쉬운 7개 서비스 분류로 고정하고, 혼잡도는 독립적인 켜기/끄기 스위치로 제공한다.

## 카테고리 구성

노출 순서와 이름은 다음 7개로 고정한다.

1. 전체
2. 촬영지
3. HOT
4. 팝업
5. 전시·행사
6. 음식점
7. 카페·디저트

각 항목은 동일한 중립 칩 문법과 일관된 아이콘을 사용한다. 선택된 항목만 브랜드 색상으로 강조한다. 가로 스크롤을 허용하되 첫 화면에서 `전체`, `촬영지`, `HOT`이 우선 보이게 한다. 영역 위에는 `장소 카테고리` 라벨을 둔다.

## 데이터 연결

- `전체`: 지도 범위 내 모든 장소.
- `촬영지`: 장소 태그 `FILMING_LOCATION`.
- `HOT`: 공개 트렌드 API가 반환하는 최신 `TRENDING` 또는 `WATCH` 장소만 사용한다. `BLOG_TREND` 태그 전체를 HOT으로 간주하지 않는다.
- `팝업`: 장소 카테고리 `POPUP`과 진행 중 팝업 행사 데이터를 함께 취급한다. 현재 데이터가 0건이어도 카테고리는 항상 노출하며, 데이터가 들어오면 UI 변경 없이 표시한다.
- `전시·행사`: 진행 중 행사 API의 좌표 데이터를 지도 마커로 표시한다. 장소 카테고리 `EXHIBITION` 데이터가 생기면 함께 포함한다.
- `음식점`: 장소 카테고리 `RESTAURANT`.
- `카페·디저트`: 장소 카테고리 `CAFE,DESSERT`.

현재 백엔드의 장소 범위 조회, 장소 트렌드, 진행 중 행사 API를 프론트엔드에서 조합한다. 이번 범위에서는 백엔드 계약을 변경하지 않는다.

장소와 행사는 식별자 네임스페이스를 분리한다. 행사 마커 선택은 장소 상세가 아니라 행사 상세로 이동해야 한다. 데이터가 없는 카테고리를 선택하면 빈 지도로 오해하지 않도록 `현재 표시할 팝업이 없어요`처럼 짧은 상태 문구를 제공한다.

## 혼잡도 컨트롤

혼잡도는 카테고리 칩 행에서 제거한다. 지도 위의 독립 플로팅 컨트롤로 `실시간 혼잡도` 라벨과 명확한 ON/OFF 스위치를 제공한다.

- 첫 방문 기본값은 OFF다.
- 사용자가 변경한 값은 로컬 저장소에 기억한다.
- 지도 집중 모드에서도 접근할 수 있다.
- ON일 때만 혼잡도 영역, 범례, 상세 패널을 표시한다.
- 스위치는 `role="switch"`와 `aria-checked`로 상태를 전달한다.

## 레이아웃과 접근성

- 검색창 아래에 카테고리 라벨과 가로 스크롤 칩을 배치한다.
- 혼잡도 스위치는 검색·카테고리 컨테이너와 시각적으로 분리한다.
- 모든 컨트롤은 최소 44px 터치 영역을 확보한다.
- 가로 스크롤 끝의 항목이 잘렸다는 단서를 남겨 추가 항목이 있음을 알린다.
- 키보드 포커스, 선택 상태, 스크린리더 이름을 제공한다.
- 지도 집중 모드에서는 검색과 카테고리는 기존처럼 축소하고 혼잡도 스위치는 유지한다.

## 오류와 빈 상태

- 카테고리 요청 실패 시 기존 지도 결과를 임의로 다른 분류처럼 표시하지 않는다.
- HOT 요청 실패 시 HOT 선택 상태에 재시도 가능한 짧은 안내를 제공한다.
- 행사 요청 실패 시 전시·행사와 팝업에만 오류 상태를 표시하고 일반 장소 필터에는 영향을 주지 않는다.
- 결과 0건은 오류와 구분해 해당 카테고리에 현재 표시할 데이터가 없다고 안내한다.

## 검증

- 7개 카테고리의 순서, 이름, 데이터 쿼리 매핑을 단위 테스트한다.
- 첫 방문 혼잡도 OFF와 마지막 선택 복원을 테스트한다.
- 혼잡도 스위치의 접근성 상태와 레이어 표시를 테스트한다.
- HOT에 `BLOG_TREND` 전체가 섞이지 않는지 확인한다.
- 장소와 행사 마커 선택이 각각 올바른 상세 화면으로 이동하는지 확인한다.
- 빈 팝업과 API 실패 상태를 구분해 테스트한다.
- 모바일 너비, 지도 집중 모드, 하단 경로 시트가 열린 상태에서 겹침을 확인한다.

## 완료 기준

- 카테고리와 혼잡도가 같은 칩 행에 섞이지 않는다.
- 카테고리는 승인된 7개만 표시된다.
- 혼잡도는 첫 방문 OFF이며 독립 스위치로 전환되고 선택이 저장된다.
- 실제 데이터 소스에 맞춰 장소, 트렌드, 행사가 지도에 표시된다.
- 현재 0건인 팝업도 빈 상태를 제공하고 향후 데이터 유입을 자동 수용한다.
