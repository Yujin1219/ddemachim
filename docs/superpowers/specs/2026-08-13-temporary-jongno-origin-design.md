# 임시 종로 출발지 고정 설계

- 상태: 사용자 승인 완료
- 작성일: 2026-08-13
- 적용 범위: `FE/**`

## 목표

로컬 경로 연동을 안정적으로 확인할 수 있도록 메인 홈의 현재 위치를 광화문광장 인근 좌표로 임시 고정한다. 브라우저 위치 권한이나 CoreLocation 상태와 무관하게 장소 선택 즉시 동일한 출발지로 경로를 계산해야 한다.

## 확정 동작

- 임시 출발지는 광화문광장 인근 `latitude: 37.5716`, `longitude: 126.9769`다.
- 메인 홈이 열리면 위치 상태는 즉시 `ready`이며 브라우저 Geolocation API를 호출하지 않는다.
- 지도 사용자 위치 마커와 `/api/routes/compare`의 `origin`은 모두 이 좌표를 사용한다.
- 현위치 버튼을 누르거나 경로 위치 재시도를 눌러도 GPS를 요청하지 않고 동일 좌표를 유지한다.
- 선택 장소를 닫아도 임시 출발지는 유지한다.
- 사용자에게 실제 GPS라는 오해를 주지 않도록 홈 상태 문구와 경로 패널 출발지 문구를 `광화문 인근`으로 표시한다.

## 검토한 접근

### 채택: 위치 훅에 고정 좌표 주입

`useCurrentLocation`이 선택적으로 `fixedLocation`을 받게 하고, `MapHome`만 임시 좌표를 전달한다. 고정 좌표가 있으면 훅은 초기 상태, `locate`, `clear` 모두 같은 `ready` 위치를 유지한다. 나중에 `MapHome`의 주입 한 줄을 제거하면 기존 GPS 동작으로 복귀할 수 있어 임시 변경의 경계가 명확하다.

### 제외: `MapHome`에서 위치 상태를 별도로 하드코딩

변경 파일은 줄지만 위치 상태와 재시도 동작이 훅 밖에서 중복되어 버튼과 경로 요청의 출발지가 어긋날 위험이 있다.

### 제외: Geolocation 실패 시에만 종로 좌표 사용

권한 요청과 CoreLocation 지연이 계속 발생하며, 테스트할 때마다 실제 위치와 임시 위치가 섞일 수 있다. 사용자는 현재 위치를 임시로 고정해 달라고 했으므로 fallback 방식은 선택하지 않는다.

## 구성

- `routeComparison.js`: 의미가 드러나는 읽기 전용 임시 광화문 좌표 상수를 제공한다.
- `useCurrentLocation.js`: 유효한 `fixedLocation`이 있으면 외부 위치 API를 호출하지 않고 고정 상태를 반환한다. 고정 좌표가 없을 때의 기존 GPS 흐름은 변경하지 않는다.
- `ProductFlow.jsx`: `MapHome`에서만 고정 좌표를 훅에 전달하고 상태 문구를 `광화문 인근을 출발지로 사용 중이에요`로 바꾼다.
- `SelectedPlaceRoutePanel.js`: 선택 장소 경로 제목을 `광화문 인근에서`로 표시할 수 있도록 출발지 라벨 prop을 받는다. 기본값은 기존 `현재 위치에서`로 유지해 다른 사용처와 테스트 호환성을 지킨다.

## 오류와 경계 조건

- 고정 좌표는 기존 좌표 정규화 함수를 통과한 값만 사용한다.
- 잘못된 `fixedLocation`이 전달되면 GPS 흐름으로 조용히 돌아가며 잘못된 좌표를 서버로 보내지 않는다.
- 고정 모드에서는 위치 권한 거부, 시간 초과, CoreLocation 오류 상태가 발생하지 않는다.
- 목적지가 고정 좌표에서 30m 이내이면 기존 `이미 목적지 근처예요` 규칙을 그대로 적용한다.
- 서버 경로 공급자 오류와 ODsay/TMAP 처리에는 영향을 주지 않는다.

## 검증

- 고정 좌표를 전달하면 최초 렌더부터 `ready`이고 위치 API를 호출하지 않는 훅 테스트
- 고정 모드의 `locate`와 `clear`가 동일한 좌표와 `ready` 상태를 유지하는 테스트
- 고정 좌표가 없으면 기존 동시 요청 공유, abort, 오류 정규화가 유지되는 회귀 테스트
- 경로 패널이 전달된 `광화문 인근에서` 라벨을 표시하고 기본 라벨은 `현재 위치에서`인 컴포넌트 테스트
- 전체 프런트엔드 테스트와 프로덕션 빌드

## 완료 기준

- 홈 진입과 장소 선택에서 위치 권한 팝업이 발생하지 않는다.
- 경로 요청 출발지는 항상 `37.5716, 126.9769`다.
- 지도와 경로 패널은 실제 GPS가 아니라 광화문 인근을 사용 중임을 명시한다.
- 고정 좌표 주입을 제거하면 기존 GPS 로직으로 복구할 수 있다.
