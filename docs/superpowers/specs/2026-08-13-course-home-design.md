# 코스 홈 UI 설계

## 목표

하단 `코스` 탭의 첫 화면을 코스 생성 조건 화면에서 코스 관리·발견 허브로 변경한다. 사용자는 예정된 내 코스, 완료한 내 코스, 다른 사용자의 공개 코스를 한 화면에서 확인하고 기존 생성 플로우로 진입할 수 있다.

## 정보 구조

1. 상단 제목 `코스`와 아이콘 버튼 `새 코스 만들기`
2. `내 코스` 영역과 `예정 | 완료` 세그먼트
3. 선택 상태에 맞는 내 코스 세로 목록
4. `다른 사람의 코스` 영역과 가로 스크롤 공개 코스 카드
5. 기존 하단 내비게이션

## 상호작용

- 코스 탭은 새 `course-home` 화면으로 이동한다.
- `+` 아이콘 버튼은 기존 `course-conditions` 화면으로 이동한다.
- 예정 코스는 기존 `route-map`, 완료 코스는 기존 `record-detail`로 이동한다.
- 공개 코스 카드는 현재 목데이터 단계에서 `route-map`으로 이동한다.
- `예정 | 완료`는 동일한 영역을 교체하는 ARIA tab 패턴으로 구현한다.

## 콘텐츠

- 예정 코스: 날짜, 코스명, 지역, 장소 수, 예상 소요 시간, 대표 이미지
- 완료 코스: 완료 날짜, 코스명, 지역, 방문 장소 수, 실제 소요 시간, 대표 이미지
- 공개 코스: 작성자, 코스명, 장소 수, 소요 시간, 저장 수, 대표 이미지
- 현재 API가 없으므로 모든 값은 UI 검증용 목데이터다.

## 시각 방향

- 기존 앱의 흰 표면, 회색 배경, 절제된 파랑과 12px 이하 카드 반경을 유지한다.
- 상단은 마케팅 hero 없이 작업 화면 크기의 제목과 아이콘 명령만 둔다.
- 내 코스는 중첩 카드가 아닌 구분선 기반 세로 행으로 스캔 가능하게 구성한다.
- 공개 코스만 이미지 중심의 개별 가로 카드로 구성한다.
- Lucide의 `Plus`, `CalendarDays`, `CheckCircle2`, `MapPin`, `Clock3`, `Bookmark`를 사용한다.

## 상태와 접근성

- 세그먼트에 `role=tablist`, 버튼에 `role=tab`, 콘텐츠에 `role=tabpanel`을 적용한다.
- 아이콘 버튼은 `aria-label=새 코스 만들기`와 tooltip을 제공한다.
- 이미지에는 코스 장소를 설명하는 대체 텍스트를 제공한다.
- 예정·완료 데이터가 없을 때는 해당 상태에 맞는 빈 화면과 새 코스 만들기 명령을 제공한다.
- 가로 목록은 키보드로 각 카드에 접근 가능하고 스크롤바를 시각적으로 과도하게 강조하지 않는다.

## 범위 제외

- 코스 목록 조회 API와 공개 범위 API
- 좋아요·저장·작성자 프로필 동작
- 코스 상세 화면 신규 구현
- 코스 생성 조건 상태의 서버 저장

## 완료 기준

- 코스 탭에서 새 코스 홈이 열린다.
- 예정·완료 전환과 세 종류의 카드가 모바일 너비에서 겹치지 않는다.
- `+` 버튼으로 기존 생성 화면에 진입한다.
- 프론트 빌드와 관련 모델 테스트가 통과한다.
