# AI 가이드 장소 추천 결과 디자인

## 목표

AI 답변과 장소 검색 결과를 시각적으로 분리해, 긴 텍스트 답변이 아니라 서비스의 추천 UI가 이어지는 경험으로 만든다. 챗 전송, 장소 상세 이동, 응답 데이터 계약은 유지한다.

## 구조

- AI 답변은 기존의 짧은 assistant 말풍선으로 렌더링한다.
- `recommendedPlaces`가 있으면 답변에 포함된 동일 장소 목록 행을 표현 계층에서 제거한다.
- 제거한 행에서 확인 가능한 도보 시간과 거리만 장소 카드 메타데이터로 사용한다.
- 추천 결과는 말풍선 밖의 독립된 `AiGuidePlaceRecommendations` 섹션으로 렌더링한다.
- 섹션 헤더에는 `근처 추천`, 전체 개수, 지도 화면으로 이동하는 `지도보기`를 표시한다.
- 최초 3개만 보여주고 나머지는 펼치기와 접기로 제어한다.

## 카드 위계

1. 52px 장소 이미지
2. 장소명
3. 카테고리
4. 실제 응답에서 추출한 도보 시간과 거리
5. 실제 거리 또는 도보 시간으로만 판단한 짧은 추천 이유
6. 장소 상세 이동 chevron

추천 이유는 목록에서 실제 최단 거리인 경우, 또는 실제 도보 시간이 있는 경우에만 만든다. 혼잡도, 분위기, 운영 상태처럼 응답으로 확인할 수 없는 내용은 만들지 않는다.

## 디자인 톤

- 기존 밝은 gray-blue 배경과 메인 블루를 유지한다.
- 카드 전체를 파란색으로 두르지 않는다.
- 흰색 surface, neutral 1px border, 15px radius, 옅은 tinted shadow를 사용한다.
- 메인 블루는 카테고리, 도보 시간, 액션에만 제한한다.
- 자동 애니메이션은 추가하지 않는다. hover, focus, active 피드백만 사용한다.
- 새로운 visible copy에는 em dash 또는 en dash를 사용하지 않는다.

## 접근성

- 장소 카드는 실제 `button`으로 유지한다.
- 펼치기 버튼에 `aria-expanded`와 추천 목록 연결 정보를 제공한다.
- 지도보기와 카드에 명확한 accessible name을 제공한다.
- 이미지에는 장소명을 포함한 대체 텍스트를 제공한다.
- 모든 액션은 키보드 focus-visible 상태를 갖는다.
