# 때마침 기능 명세서 v2

> 때마침의 화면 및 사용자 플로우별 기능 범위, 담당 영역, 상세 동작과 우선순위를 정의한다.

## 문서 정보

- 총 기능 수: **49개**
- 원본: Notion 내보내기 Markdown 1개와 동일한 내용의 CSV 2개
- 정리 방식: 중복 CSV 및 빈 행 제거, 사용자 플로우별 재배치, 원본 필드 보존
- 원본 필드: 기능명, 담당자(FE/BE), 비고, 상세 동작, 우선순위, 페이지 구분, 플로우

## 핵심 정책

- 코스 바구니에 담긴 장소는 전체 방문을 기본 원칙으로 하며, 시스템이 장소를 자동 제외하지 않는다.
- 전체 방문이 불가능하면 불가능 사유와 체류시간 단축, 종료시간 연장, 순서 변경 등의 조정안을 제시한다.
- 주변 추천 장소는 사용자 승인 후에만 코스에 포함한다.
- 일반 장소는 외부 지도 API 결과를 활용할 수 있으며, 큐레이션 콘텐츠 없이도 개인 필수 일정과 코스 계산에 포함한다.
- 자유 후기는 참고 정보로 제공하고, 추천 여부·혼잡도·대기시간·실제 체류시간 등 구조화된 평가를 일정 보정에 활용한다.
- 위치 기반 기능은 권한 거부, GPS 오차, PWA 백그라운드 위치 추적 제약을 고려한다.

## 구현 시 공통 확인사항

- 인증이 필요한 기능은 비로그인 상태의 진입 및 로그인 후 복귀 경로를 함께 정의한다.
- 위치 기반 기능은 권한 허용, 권한 거부, 좌표 미수신, GPS 오차 상태를 구분한다.
- 목록 및 지도 기능은 로딩, 빈 결과, 오류, 재시도 상태를 제공한다.
- 코스 변경은 예상 도착시간, 종료시간, 이동시간과 전체 방문 가능 여부를 함께 재계산한다.
- 기간성 장소는 운영 종료일과 정보 기준 시각을 명확히 표시한다.
- 사용자 생성 콘텐츠는 작성자 권한과 수정·삭제 가능 범위를 검증한다.
